# How to choose fields to show

This guide explains how to configure which fields are shown on the grid.

Configure the grid using the field list.

## What's shown by default

If your application starts without a predefined layout:

- The flat table displays all the available fields.

- In the pivot table, the first two non-numeric fields from the data are placed in **Rows** and **Columns**, while the first numeric field is placed in **Values**.

## Add fields

<h3 id="add-fields-in-the-pivot-table">In the pivot table</h3>

**Step 1.** Select the checkbox next to a field in the **All fields** box, or drag the field into the **Rows**, **Columns**, **Values**, or **Report filters** box.

When you use the checkbox, the field is placed automatically based on its data type: string fields are added to **Rows**, and numeric fields are added to **Values** as measures.

**Step 2.** Select **Apply** in the field list.

Measures are shown in the **Columns** box by default. To display them in the rows instead, drag the **Σ Values** item into the **Rows** box.

<h3 id="add-fields-in-the-flat-table">In the flat table</h3>

**Step 1.** Select the checkbox next to the field to display it in the table. To display all the available fields at once, select the **Select all** checkbox.

**Step 2.** Select **Apply** in the field list.

## Rearrange fields

<h3 id="rearrange-fields-in-the-pivot-table">In the pivot table</h3>

**Step 1.** Change the order of fields within the **Rows**, **Columns**, or **Values** box by dragging them up or down.

**Step 2.** Select **Apply** in the field list.

<h3 id="rearrange-fields-in-the-flat-table">In the flat table</h3>

**Step 1.** Drag a field up or down to change the order of the columns.

**Step 2.** Select **Apply** in the field list.

## Remove fields

<h3 id="remove-fields-in-the-pivot-table">In the pivot table</h3>

**Step 1.** Drag a field out of the **Rows**, **Columns**, **Values**, or **Report filters** box, or clear the checkbox next to the field in the **All fields** box.

**Step 2.** Select **Apply** in the field list.

<h3 id="remove-fields-in-the-flat-table">In the flat table</h3>

**Step 1.** Clear the checkbox next to a field to remove it from the flat table. If all the fields are selected, you can use the **Select all** checkbox to clear them at once.

**Step 2.** Select **Apply** in the field list.

# Toolbar

A toolbar is a collection of the most commonly used features. It is usually displayed above the grid, but it can also be positioned vertically beside it.

This guide describes the toolbar tabs and how to use them.

## Use full-screen mode

To view the grid on the whole screen, select the **Fullscreen** tab.

To return to the normal view, select **Minimize** or press **Esc**.

## Show the hidden tabs

When the toolbar is too narrow to fit all the tabs, the remaining tabs are collapsed and the **More** tab appears.

Select **More** to display the hidden tabs. To collapse them again, select **Less**.

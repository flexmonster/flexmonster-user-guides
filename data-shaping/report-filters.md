# Report filters

If you want to filter by a field but don't want to show its values on the grid, use the report filters. Members of such fields aren't displayed on the grid, helping maintain a clean, uncluttered report.

## About report filters

Report filters can be added only in the pivot table.

Note that a field in the **Report filters** box doesn't change the data on its own. To display different subsets of data, apply a member or a conditional filter to the field.

Sorting has no effect on the fields placed in the **Report filters** box.

## Add report filters

**Step 1.** Open the field list.

**Step 2.** Drag the fields you need to the **Report filters** box.

**Step 3.** Select **Apply** in the field list.

**Step 4.** Configure a filter for each field you added. The fields appear in the upper-left corner of the grid—select a field's name there to open its filter view.

## Remove report filters

Report filters are removed the same way as the fields in the **Rows**, **Columns**, and **Values** boxes:

**Step 1.** Open the field list.

**Step 2.** Drag the field out of the **Report filters** box, or clear the checkbox next to the field in the **All fields** box.

**Step 3.** Select **Apply** in the field list.

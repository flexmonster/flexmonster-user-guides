# Sorting

This guide explains how to sort field members in the pivot and flat tables, and how to sort members by values in the pivot table.

## Default sort order

Before you apply any sorting:

- In the pivot table, members are sorted in ascending order.

- In the flat table, records appear in the order they have in the data source.

## Sort field members

### In the pivot table

**Step 1.** Open the filter view by selecting the field’s name.

**Step 2.** Next to **Sort**, select **AZ** to sort field members in ascending order, or **ZA** to sort them in descending order.

**Step 3.** Select **Apply** in the filter view.

### In the flat table

**Step 1.** Hover over the field header. The sorting arrows will appear.

**Step 2.** Select the arrow to change the sort order: the first time sorts members in ascending order, the second time in descending order, and the third time removes sorting, so the records return to the order they have in the data source.

Alternatively, you can sort in the filter view, the same way as in the pivot table.

## Sort by values

In the pivot table, you can also sort members by the values shown on the grid:

**Step 1.** Hover over the member whose values you want to sort by. The sorting arrows will appear.

**Step 2.** Select the arrow to change the sort order: the first time sorts members in ascending order, the second time in descending order, and the third time removes the sorting.

# Saving and restoring reports

A report is a snapshot of the current view: the data you are looking at, the layout, and all the fields, filters, sortings, and aggregations you applied. You can save a report to a file and restore it later.

## Save a report

**Step 1.** Select the **Save** button on the toolbar. As a result, the confirmation dialog will appear.

**Step 2.** Select **Save**.

The report is downloaded to your computer as a JSON file.

## Restore a report

You can restore a report from a file on your computer or from a link.

### From your computer

**Step 1.** Select the **Open** button on the toolbar. As a result, the **Open** dialog will appear.

**Step 2.** In the dialog, select **Open**. As a result, the file manager will appear.

**Step 3.** In the file manager, find and select the report file you need.

### From a link

**Step 1.** Select the **Open** button on the toolbar. As a result, the **Open** dialog will appear.

**Step 2.** Enter the URL of the report in the input field.

**Step 3.** Select **Open**.

# Connect to CSV data

You can connect to CSV data by its URL or to a CSV file from your computer.

## Connect to remote data

**Step 1.** On the toolbar, select ![](../assets/icons/toolbar_button_connect.svg) **Connect**. As a result, the **Connect** dialog will appear.

**Step 2.** Switch to the **CSV** tab.

**Step 3.** Enter the URL to your CSV data in the input field.

**Step 4.** Select **Apply**.

## Connect to local data

**Step 1.** On the toolbar, select ![](../assets/icons/toolbar_button_connect.svg) **Connect**. As a result, the **Connect** dialog will appear.

**Step 2.** Switch to the **CSV** tab.

**Step 3.** Select the **Open** button. As a result, the file manager will appear.

**Step 4.** Select the file via the file manager.
